# Fatsa Karta Game

Ένα διασκεδαστικό παιχνίδι όπου βάζεις το κινητό στο μέτωπο και προσπαθείς να μαντέψεις τον διάσημο!

## Δομή

- `index.html`: Η κύρια σελίδα
- `css/style.css`: Το στυλ της εφαρμογής
- `js/api.js`: Λήψη δεδομένων από Wikidata
- `js/game.js`: Λογική παιχνιδιού

## Πώς να παίξετε

1. Ανοίξτε το `index.html` στον browser σας.
2. Πατήστε "ΠΑΙΞΕ ΤΩΡΑ".
3. Τοποθετήστε το κινητό στο μέτωπο.
4. Οι φίλοι σας περιγράφουν τον διάσημο που εμφανίζεται!
